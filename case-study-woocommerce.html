Turning a Custom WordPress Website Into a WooCommerce Store

A real-world look at adding WooCommerce, product categories, variations, cart, checkout, and payment functionality to an existing WordPress and Elementor website — without rebuilding it from scratch.

The Challenge
01

Products that didn't start out as WooCommerce products

The website already had its own design, content, and product presentation, built with WordPress and Elementor. The products were not initially structured as standard WooCommerce products — the site was using a custom post type instead. That meant the task wasn't as simple as installing WooCommerce, adding products, and calling it done.

The existing website had to be understood first, and the new e-commerce functionality then needed to work alongside the existing WordPress and Elementor structure while maintaining a consistent user experience. Requirements also evolved over the course of the project, requiring several rounds of adjustments.

My Approach
02

Work with what already exists

Rather than rebuilding the site, the approach was to understand the existing architecture first, identify exactly what needed to change, and then add the required WooCommerce functionality without unnecessarily disrupting the rest of the website. That meant integrating WooCommerce carefully into the existing structure rather than replacing the existing design.

As requirements evolved during development — including a request for the shop to work more like a category-first browsing experience — the store was adjusted and refined through several rounds of revisions rather than treating the first implementation as final.

What I Did

Turning the site into a working store

01

WooCommerce Implementation

Implemented WooCommerce into the existing WordPress website so products could be managed and sold through a proper e-commerce system, integrated carefully into the existing structure rather than replacing the existing design.

02

Product Setup

Set up and organized roughly 60 products within WooCommerce so they could be used as part of the store's purchasing system — a number that grew as additional products were added during the project.

03

Product Categories

Implemented a category-based structure so customers could browse relevant categories instead of one large product list. The live site organizes products under categories including Firewood, Sand/Soil, Mulches, Stones & Gravel, and Garden Features.

04

Product Attributes & Variations

Set up WooCommerce attributes and variations so different options could be associated with individual products, since not every product is sold as a single fixed item.

05

Cart & Checkout

Worked on the purchasing flow, making sure products could be added to the cart and that the relevant WooCommerce shopping and checkout functionality was in place.

06

Payment Gateway

Configured a Stripe payment gateway in test mode, allowing payment functionality to be incorporated into the WooCommerce setup while the client's live payment credentials could be connected separately.

07

WooCommerce Styling

Styled the WooCommerce components to work visually with the existing website, so the shopping experience fit into the existing WordPress/Elementor design rather than feeling like a separate system.
